# Reconocimiento de dígitos con CNN

## Problema
Clasificar imágenes de dígitos escritos a mano en las clases 0 a 9.

## Solución
Se implementa una red neuronal convolutiva con Keras utilizando Conv2D, MaxPooling2D, Flatten, Dense y Dropout, junto con normalización, entrenamiento y evaluación.

## Componentes
- `Prueba_CNN_Reconocimiento_Digitos.py`
- `Prueba_CNN_Reconocimiento_Digitos.ipynb`
- `Informe_Prueba_CNN_Reconocimiento_Imagenes.pdf`

## Habilidades demostradas
Deep Learning, CNN, Keras, visión computacional, regularización, métricas y análisis de resultados.
