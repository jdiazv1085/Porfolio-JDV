# Modelo predictivo en Apache Spark MLlib

## Problema
Clasificar transacciones como normales o riesgosas a partir de variables comerciales y temporales.

## Solución
Se construye un pipeline reproducible con Apache Spark MLlib que incluye indexación y codificación de variables categóricas, ensamblaje y escalamiento de features, división entrenamiento/prueba y Logistic Regression.

## Componentes
- `Prueba_Modelo_Predictivo_Spark_MLlib.py`
- `Prueba_Modelo_Predictivo_Spark_MLlib_Colab.ipynb`
- `Informe_Prueba_Modelo_Predictivo_Spark_MLlib.pdf`

## Habilidades demostradas
PySpark, MLlib, preparación de datos, clasificación binaria, pipelines, evaluación de modelos y análisis aplicado al negocio.
