# Solución Big Data para cadena de supermercados

## Problema
Anticipar quiebres de stock durante eventos de alta demanda y mejorar la reasignación de inventario.

## Solución
Se diagnostica el caso mediante las 5V del Big Data y se propone una arquitectura con ingesta de múltiples fuentes, procesamiento distribuido con Apache Spark, almacenamiento escalable y visualización de indicadores.

## Componente principal
- `Desafio_Big_Data_Supermercados.pdf`

## Habilidades demostradas
Arquitectura Big Data, Apache Spark, diseño de soluciones, integración de fuentes, KPI y análisis estratégico.
