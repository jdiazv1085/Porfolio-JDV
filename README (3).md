## Proyectos destacados

### 1. Modelo predictivo de transacciones riesgosas con Apache Spark MLlib

Pipeline de clasificación binaria que integra preparación de features, `StringIndexer`, `OneHotEncoder`, `VectorAssembler`, `StandardScaler`, `LogisticRegression`, división train/test, predicciones y evaluación mediante Accuracy, F1 y AUC.

[Ver proyecto](projects/spark-mllib/README.md)

### 2. Reconocimiento de dígitos con redes neuronales convolutivas

Modelo CNN para clasificación de imágenes de dígitos de 8×8 píxeles, con normalización, convolución, pooling, dropout, early stopping y evaluación mediante accuracy, loss y matriz de confusión.

[Ver proyecto](projects/cnn-digitos/README.md)

### 3. Diseño de solución Big Data para supermercados

Diagnóstico con las 5V del Big Data y propuesta de arquitectura orientada a anticipar quiebres de stock, integrando ingesta, Apache Spark, almacenamiento y visualización.

[Ver proyecto](projects/big-data/README.md)
